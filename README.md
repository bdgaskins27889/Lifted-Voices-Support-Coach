# Lifted Voices Support Coach

**Pre-release prototype. Not approved for clinical, crisis, emergency or HIPAA-regulated use.** Do not share health information or other sensitive personal information.

## Setup
```sh
npm install
npm start
```
Set VERIFY_TOKEN, PAGE_ACCESS_TOKEN, APP_SECRET, OPENAI_API_KEY, OPENAI_MODEL securely in the hosting environment.

## Required before launch
Review data flows and privacy/consent, contractual and applicable HIPAA requirements. Test signature verification, platform integration, API model availability, crisis escalation, access controls, rate limits, error handling, referral resources, and human oversight. Do not advertise HIPAA compliance without substantive evidence.
